Datenschutzerklärung

Stand: 22. September 2026

1. Verantwortlicher und Kontakt

Verantwortlich für dieses private Lernprojekt ist der Inhaber des GitHub-Kontos linusscodingg. Kontakt ist über das GitHub-Repository möglich. Für eine breitere öffentliche Nutzung sollte hier zusätzlich eine direkte Kontaktadresse des Betreibers ergänzt werden.

2. Welche Daten verarbeitet werden

Für die Nutzung der veröffentlichten Website ist eine Anmeldung mit GitHub über Firebase Authentication erforderlich. Dabei werden folgende Daten verarbeitet:

  • Firebase-Nutzer-ID sowie die von GitHub für die Anmeldung bereitgestellten Profildaten, beispielsweise Benutzername, Profilbild und – sofern verfügbar – E-Mail-Adresse;
  • Quizversuche, Punktzahlen, Zwischenstände und Zeitpunkte der Synchronisation;
  • bei freiwilliger Teilnahme am Lernvergleich: frei gewählter Anzeigename sowie zusammengefasste Best- und Durchschnittsnoten pro Fach und Quiz;
  • technisch notwendige Verbindungs- und Sicherheitsdaten wie IP-Adresse, Browserinformationen und Serverprotokolle bei GitHub und Google/Firebase.

Das Dashboard erhält und speichert kein GitHub-Passwort. Die Anmeldung wird über GitHub und Firebase Authentication verarbeitet; das Dashboard fordert keinen Zugriff auf private Repositories an.

3. Zweck

Die Daten werden verwendet, um das Dashboard bereitzustellen, den persönlichen Lernfortschritt zwischen Geräten zu synchronisieren, den freiwilligen Lernvergleich zwischen angemeldeten Nutzern anzubieten, Konten zu schützen und technische Angriffe oder Fehler zu erkennen. Es findet keine Werbung, Profilbildung zu Marketingzwecken oder Weitergabe zu Werbezwecken statt.

4. Eingesetzte Dienste und Übermittlung ins Ausland

Die Website wird über GitHub Pages bereitgestellt. Anmeldung und Cloud-Speicherung erfolgen über Google Firebase. Dabei können Daten durch GitHub, Inc. und Google LLC beziehungsweise deren verbundene Unternehmen auch ausserhalb der Schweiz verarbeitet werden. Es gelten ergänzend die Datenschutzhinweise von GitHub und die Datenschutzhinweise von Google.

5. Lokale Speicherung und Cookies

Das Dashboard verwendet lokalen Browser-Speicher als Zwischenspeicher für den Quizfortschritt. Firebase Authentication kann technisch notwendige Browser-Speicherungen für die angemeldete Sitzung verwenden. Es werden keine Analyse-, Werbe- oder Marketing-Cookies eingesetzt.

6. Speicherdauer und Löschung

Lokale Daten bleiben gespeichert, bis der Browser-Speicher gelöscht oder eine Sicherung zurückgesetzt wird. Cloud-Daten bleiben bis zur Löschung des Kontos gespeichert. Der freiwillige Eintrag im Lernvergleich kann jederzeit über „Nicht mehr anzeigen“ separat entfernt werden. Angemeldete Nutzer können über „Konto löschen“ das Firebase-Konto, den Cloud-Fortschritt und den Eintrag im Lernvergleich löschen. Vorher kann über „Sicherung exportieren“ eine lokale Kopie erstellt werden.

7. Sicherheit

Private Quizdaten werden durch Firebase Authentication und Firestore Security Rules auf das jeweils angemeldete GitHub-Konto beschränkt. Im freiwilligen Lernvergleich sind nur Anzeigename und aggregierte Noten für andere angemeldete GitHub-Nutzer lesbar; E-Mail-Adresse, einzelne Antworten und Fehler werden dort nicht veröffentlicht. Trotz angemessener Massnahmen kann keine Internetübertragung vollständig risikofrei garantiert werden.

8. Rechte

Betroffene Personen können Auskunft, Berichtigung oder Löschung ihrer personenbezogenen Daten verlangen. Dafür ist der oben genannte Kontakt zu verwenden. Änderungen an dieser Erklärung werden auf dieser Seite veröffentlicht.

Dieses Dashboard ist ein inoffizielles privates Lernprojekt. Die angezeigte Lernnote ist keine offizielle Bewertung.
